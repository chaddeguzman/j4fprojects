Library layers

What each folder controls

1 inbound/

Temporary source files waiting to be processed.

3 references/

Shared context, standards, examples, coding practices, and review guidance.

4 templates/

Gold-standard structures for tech specs, functional specs, and other reusable outputs.

6 skills/

Reusable Markdown instructions that tell Codex what kind of work to perform.

2 outbound/

Generated Markdown documents created from the source, skill, references, and template guidance.

5 harness/

Runner scripts and logs that coordinate the local workflow.
